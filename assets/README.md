# Asset Management (`assets/`)

This directory houses all static visual media, branding graphics, collage artwork, and book cover images for **The Reading Chamber**.

---

## Folder Structure

```
assets/
├── books/       # Curated 2:3 high-res front book covers
├── branding/    # Official podcast logo, typography badges, and avatars
├── collage/     # Editorial cutout collage graphics (Thinker, Athens, mics)
└── references/  # Design reference mockups and wireframes
```

---

## Book Cover Specifications (`assets/books/`)

For full details, consult the comprehensive guide in `docs/book-cover-guide.md`.

* **Aspect Ratio**: Strictly `2:3` (e.g. 600 x 900 px or 800 x 1200 px).
* **Format**: Front cover flat artwork only (no 3D mockups or skewed angles).
* **Optimization**: Keep file size between 50 KB and 300 KB (JPEG / WebP / PNG).
* **Naming Convention**: `ep-<videoId>-<index>-<slug>.jpg` or `<slug>.jpg`.

---

## Collage Graphics (`assets/collage/`)

* All collage graphics should have transparent backgrounds (PNG or SVG).
* Maintain high-contrast editorial cutouts aligned with the brand aesthetic (black, gold, paper cream, vibrant yellow).
